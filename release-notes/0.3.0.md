Igloo 0.3.0

This release adds Thaw to the wizard, shows the space that each run freed, and installs updates from the app.

- The wizard can thaw several Frozen projects in one run. You confirm one Thaw plan. Each project gets its own result.
- Thaw does not install dependencies. Reinstall them in each project after a Thaw.
- Results show the space that Igloo measured next to the estimate. Space in the Trash is shown separately, because it is freed only when you empty the Trash.
- Task history and the igloo history command show the same values.
- After a verified download, Install and relaunch replaces the app and starts the new version. If a step fails, the old app stays in place.
- Many result and Thaw screens use clearer words and layout.

After an update, macOS can ask again for permissions that you gave to Igloo.

Update notes in installed 0.2.0 and 0.1.0 apps still show the raw text of this page. Newer versions show it formatted.

Requires macOS 14 or later.
Choose the standard DMG with Python included, or the smaller system-Python build for Python 3.11 or later.
Git and gh are needed for repository features.

This release is not notarized or signed with Apple Developer ID.
If macOS blocks it, try opening Igloo, then approve it in System Settings > Privacy & Security > Open Anyway.
