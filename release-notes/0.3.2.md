Igloo 0.3.2

This release fixes the in-app update.

- Install and relaunch now installs the update. In 0.3.0 and 0.3.1 it stopped with the message "The update archive contains an unexpected item."
- Long release notes in the update window no longer overlap the other controls.

To update from 0.3.0 or 0.3.1, choose Igloo > Check for Updates…, then Install and relaunch.
To update from 0.2.x or older, open the DMG, drag Igloo to Applications, and replace the old app.

After an update, macOS can ask again for permissions that you gave to Igloo.

Requires macOS 14 or later.
Choose the standard DMG with Python included, or the smaller system-Python build for Python 3.11 or later.
Git and gh are needed for repository features.

This release is not notarized or signed with Apple Developer ID.
If macOS blocks it, try opening Igloo, then approve it in System Settings > Privacy & Security > Open Anyway.
