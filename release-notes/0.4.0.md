Igloo 0.4.0

This release gives Freeze and Thaw their own look and makes the app fit small windows.

- Freeze uses ice blue. Thaw uses gold. A small igloo shows on the Freeze and Thaw results. Motion stops when Reduce Motion is on.
- The wizard is now called Project wizard. The cleanup list is now called Cleanup candidates.
- A disabled button says why it is disabled.
- The Freezer, Trash history, Task history and the review sheets fit the minimum window width. Their buttons stay visible.

To update from 0.3.0, 0.3.1 or 0.3.2, choose Igloo > Check for Updates…, then Install and relaunch.
To update from 0.2.x or older, open the DMG, drag Igloo to Applications, and replace the old app.

After an update, macOS can ask again for permissions that you gave to Igloo.

Requires macOS 14 or later.
Choose the standard DMG with Python included, or the smaller system-Python build for Python 3.11 or later.
Git and gh are needed for repository features.

This release is not notarized or signed with Apple Developer ID.
If macOS blocks it, try opening Igloo, then approve it in System Settings > Privacy & Security > Open Anyway.
