# Igloo 0.1.0

Make space. Keep your work. The first public release of Igloo for macOS.

- Explore project disk use, Git state, and inactive work.
- Review cleanup plans, freeze projects, and thaw them later.
- Save tasks and schedule reviews or cache cleanup from the app or CLI.

Requires macOS 14 or later. Choose the standard DMG with Python included, or the smaller system-Python build for Python 3.11+. Git and gh are needed for repository features.

This release is not notarized or signed with Apple Developer ID. If macOS blocks it, try opening Igloo, then approve it in **System Settings → Privacy & Security → Open Anyway**. [Apple’s instructions](https://support.apple.com/en-us/102445).
