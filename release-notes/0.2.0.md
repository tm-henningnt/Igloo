# Igloo 0.2.0

Make space. Keep your work. This release makes preservation and cleanup easier to review.

- Preserve local files and Git recovery in the Freezer while keeping your checkout, or Freeze after verification to remove reviewed checkouts. A requirements checklist helps resolve blockers before Review.
- See the expected outcome before accepting cleanup, preservation, freezing, wizard and task actions. Put projects on Hold to exclude them from wizard and task proposals.
- Back up the Freezer to a chosen folder and verify copies. Cloud backup requires confirmation because local-only files upload unencrypted.
- Use `igloo review` to prepare a task Review. Update checks explain failures and provide a link to releases.

Requires macOS 14 or later. Choose the standard DMG with Python included, or the smaller system-Python build for Python 3.11+. Git and gh are needed for repository features.

This release is not notarized or signed with Apple Developer ID. If macOS blocks it, try opening Igloo, then approve it in **System Settings → Privacy & Security → Open Anyway**. Apple Support describes this in the article "Safely open apps on your Mac".
