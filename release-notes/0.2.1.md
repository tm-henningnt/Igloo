Igloo 0.2.1

This release polishes the windows and the text in 0.2.0.

- Update notes now show headings, bullets and links as formatted text.
- Lists use the right plurals, and sizes use one number format.
- Blocked projects show a warning icon and say what to do next.
- Help, the Freezer and the update messages use plainer words.
- The push and GitHub repositories windows explain what each action does.
- Windows fit at the smallest size without cut text.

Update notes in installed 0.2.0 and 0.1.0 apps still show the raw text of this page. Newer versions show it formatted.

Requires macOS 14 or later.
Choose the standard DMG with Python included, or the smaller system-Python build for Python 3.11 or later.
Git and gh are needed for repository features.

This release is not notarized or signed with Apple Developer ID.
If macOS blocks it, try opening Igloo, then approve it in System Settings > Privacy & Security > Open Anyway.
