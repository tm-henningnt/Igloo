A little room for
your next project.

Projects pile up. Dependencies grow. Igloo helps you see what’s taking up space, clean up what you can rebuild, and preserve the work you want to return to.

Get Igloo for Mac ↓

macOS 14 or later · Python included

Quiet projects.
Nothing forgotten.

Keep recent work close. Clean up older projects. Freeze the ones that can wait. You set the ages and review the plan before Igloo gets to work.

See what’s there
Explore disk use by age, project type, or technology. Check uncommitted files, unpushed branches, worktrees, and stashes before making room.
Clear the rebuildable
Remove old dependencies and caches with a preview first. Active projects stay out of the plan unless you include them.
Freeze. Thaw. Carry on.
Preserve local files in an archive, push reviewed source, and remove the checkout after verification. Thaw a frozen project or clone another repository when you’re ready.

Find the space
worth saving.

Sunburst, icicle, and Marimekko charts make large folders easier to spot. Follow the warm-to-cold age colors, filter the view, and open a project for a closer look.

A routine you can keep.

Save your rules as tasks. Run them from the app or the igloo CLI, then schedule daily or weekly reviews. Allow automatic cache cleanup when you’re happy with the scope and limits; freezing stays held for review.

Read the CLI and scheduling guide →
igloo create weekly-review \
  --cache-days 45 --freeze-days 180
igloo plan weekly-review

Make some space.

Open the DMG, drag Igloo to Applications, then choose your projects folder in Settings. Your first scan changes nothing.

This release is not notarized. If macOS blocks the first launch, try opening Igloo, then approve it in System Settings → Privacy & Security → Open Anyway. Apple’s instructions.

Already maintain Python?

The smaller system-Python build needs Python 3.11 or later. Select your interpreter in Settings. In-app updates keep your chosen build.
