A little room for
your next project.

Projects pile up. Dependencies grow. Igloo helps you see what’s taking up space, clean up what you can rebuild, and preserve the work you want to return to.

Get Igloo for Mac ↓

macOS 14 or later · Python included

Quiet projects.
Nothing forgotten.

Keep recent work close. Clean up older projects. Freeze the ones that can wait. You set the ages and review the proposed changes before Igloo gets to work.

See what’s there
Explore disk use by age, project type, or technology. Check uncommitted files, unpushed branches, worktrees, and stashes. A badge flags a known blocker; the requirements checklist helps you resolve it.
Clear the rebuildable
Review dependencies and caches before moving them to Trash. Put a project on Hold to exclude it from wizard and task proposals.
Preserve. Freeze. Thaw.
Preserve local recovery in the Freezer and push reviewed source while keeping the checkout. Review the expected outcome, then accept once to Freeze and remove verified checkouts; thaw when you’re ready.

Find the space
worth saving.

Sunburst, icicle, and Marimekko charts make large folders easier to spot. Follow the warm-to-cold age colors, filter the view, and open a project for a closer look.

A routine you can keep.

Save your rules as tasks. Run them from the app or the igloo CLI, then schedule daily or weekly reviews. Allow automatic cache cleanup when you’re happy with the scope and limits; freezing stays held for review.

Read the CLI and scheduling guide →
igloo create weekly-review \
  --cache-days 45 --freeze-days 180
igloo review weekly-review

Make some space.

Open the DMG, drag Igloo to Applications, then choose your projects folder in Settings. Your first scan changes nothing.

The standard app includes its own Python runtime for Igloo. It doesn’t change your other Python installations.

Already maintain Python?

The smaller system-Python build needs Python 3.11 or later. Select your interpreter in Settings. In-app updates keep your chosen build.
