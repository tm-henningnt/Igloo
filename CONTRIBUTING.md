# Contributing to Igloo

[Open an issue](https://github.com/tm-henningnt/Igloo/issues) for bugs, questions, or feature ideas. For a bug, include your macOS version, Igloo version, what you expected, and what happened. Remove private paths, repository details, and secrets from anything you share.

Pull requests are welcome. For a larger change, open an issue first so we can agree on the approach. Keep each PR focused, explain the resulting behavior, and describe how you checked it. Include screenshots for interface changes using fictional projects rather than a personal catalog.

The [development guide](docs/development.md) covers local builds and tests. Use disposable projects when checking cleanup, freezing, or recovery. The maintainer handles official builds and releases.
